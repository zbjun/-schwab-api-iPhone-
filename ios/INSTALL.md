## 签名与首次授权

1. 将个人版 IPA 导入自己安排的签名工具，签名后安装到 iPhone；未签名 IPA 不能直接安装。默认 Bundle ID 为 `app.personal.ths`。
2. 打开 App，个人配置成功存入钥匙串后，连接页直接显示“打开 Schwab 登录”。本人仍需在券商页面登录并授权。
3. Schwab 应用的 Callback URL 应为 `https://127.0.0.1`。授权完成、浏览器跳到本机地址后，复制地址栏的完整最终链接，回到 App 主动粘贴并完成连接。券商密码只在券商页面输入。
4. 可先打开“演示模式”，体验行情、图表、下单与撤改；演示操作不会发送给券商。关闭演示后再核对真实账户。

个人 IPA 内包含可提取的应用配置；设备会话存入钥匙串。账户密码、OAuth 令牌和授权回调链接不需要提供给签名方。签名会改变文件校验值，更换签名团队可能改变钥匙串访问权限，仍需真机验证。

这是 SwiftUI 原生 App，Expo EAS 仅提供云端构建。Expo Go 不能导入此 IPA；若改用 Expo Go，需要先迁移至 Expo / React Native。

## 真机调试顺序

- 切换 iPhone 16 Pro 的系统明暗模式，核对自选与详情同步变化、左滑多股走势和返回导航。
- 核对盘前 / 盘后底色、标签及真实返回时间，拖动和缩放后价格与成交量分区应保持一致。
- 检查五个主图选项，以及“更多”中的六种分钟蜡烛和 MA5/10/20/30。
- 展开图下买卖区，确认键盘出现后仍能看清主图；检查大字体、按金额换算和买卖预估数量。
- 检查“买 / 卖 / 撤”切换，先用演示委托走通选单、保留订单返回和确认撤销，核对区不能遮挡主图。
- 使用真实授权只读核对账户尾号、持仓、报价时间、订单状态和图表。
- 分别测试 Wi-Fi 与蜂窝网络的直连及失败恢复，再验证关闭重开 App 和令牌刷新。
- 最后才由本人填写并确认真实订单，检查券商回执和实际订单状态；开发测试没有替你发送真实订单。

如果提交或撤改结果不确定，先查看券商订单。App 不会自动重新发送。只有本人核实上次结果后，才通过“我已核对”解除本机提示。

有 Mac 时可打开 `ios/THS.xcodeproj`，选择 THS Scheme、自己的开发团队和设备，先 Test 再 Run。本机 Windows 负责源码与工程检查，原生编译和模拟器验证使用云端 Xcode。
