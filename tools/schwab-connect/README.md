# Schwab 本机授权与只读测速工具

这是当前 Windows 电脑上的接入验证工具，还不是 iOS App 或可签名 IPA。它用于完成真实 OAuth 授权，再对比账户、持仓及 AAPL 行情接口的直连与代理响应时间。需要 Node.js 24.5 或更新版本以支持显式代理配置。

## 使用

在项目目录运行：

```powershell
node .\tools\schwab-connect\server.mjs
```

打开 `http://127.0.0.1:8765`。服务只绑定本机回环地址。

1. 在 Schwab 开发者门户将应用的 Callback URL 修改为 **`https://127.0.0.1`**，与工具显示值一致。该地址用于本次个人手动回调流程；原先的 `api.example.com` 是示例域名，不能继续使用。若修改后状态进入待审批，需恢复为 Ready For Use 后再授权，等待时间由 Schwab 决定。
2. 在本机页面输入 Client ID 与 Client Secret，或预先填写项目根目录的 `.env`。页面不会显示从文件读取的密钥。此前截图中显示过的 Secret 建议更换后再使用。
3. 点击登录按钮，在新打开的 Schwab 官方页面登录并授权自己的账户。
4. 授权结束后，浏览器会转到 `https://127.0.0.1/?code=...&state=...` 一类地址。由于未启动 HTTPS 回调服务，浏览器可能显示连接失败；从地址栏复制完整 URL，回到本机工具粘贴并完成授权。不要把这个 URL、授权码或令牌发送到聊天、搜索引擎或其他网站。不需要绕过证书警告。
5. 选择直连、当前代理或两者对比，再点击只读测速。支持本机 HTTP 代理，默认地址为 `http://127.0.0.1:7897`，可通过进程环境变量 `SCHWAB_PROXY_URL` 修改；仅接受无凭据的 127.0.0.1 HTTP 代理。可选择同时测量 AAPL 行情。当前 Schwab 应用若没有相应行情权限，行情请求可能被拒绝，这不算成功的行情加载耗时。
6. 对比模式每个接口、每条线路先预热一次，再交替测量并交替先后顺序；预热耗时单列，不计入中位数、P95、最慢、超过 1 秒次数和标准差。选择 20 次且启用行情时，共 80 次正式请求和 4 次预热，通常需要 2–4 分钟。每次请求之间至少等待 1 秒。

回调地址是固定的个人手动流程，无需域名或静态托管。Schwab 社区客户端也提供手动复制 URL 的个人授权路径；本工具使用相同的授权端点与授权码交换方式，增加来源、state、一次性消费及超时校验。[schwab-py 手动授权说明](https://schwab-py.readthedocs.io/en/latest/auth.html#schwab.auth.client_from_manual_flow)

## 数据和测试范围

### 夜盘历史覆盖诊断

完成本机授权后点击“检查夜盘数据”。只直连读取三次 `pricehistory`：SNDU 与 App 相同的 10 天/1 分钟参数、SNDU 明确起止时间的最近 10 天、QQQ 对照；均设置 `needExtendedHoursData=true`。页面按美东日期统计夜盘（20:00–04:00）、盘前、盘中、盘后根数及最早/最晚时间，不输出原始响应、凭据或账户数据。401/429 停止继续请求；错误响应不能解释成零根夜盘。

这项结果只能说明该次请求返回的历史覆盖，不能单独证明所有 Schwab API 都不支持夜盘，也不代表该股票的交易权限。手机中的 Keychain 授权不会自动共享到电脑，需要独立完成本机授权。

- 密钥和访问/刷新令牌用于当前 Node.js 进程；页面输入不会写入文件、浏览器存储或日志。关闭程序后，内存中的授权失效；手动填写的 `.env` 文件仍保留在本机，并由 Git 忽略规则排除。
- 工具不会把账户、持仓、余额或响应正文发给浏览器，只返回 HTTP 状态、数据量、耗时和连接复用信息。
- 接口仅允许 OAuth 的 POST，以及账户/持仓和指定行情的 GET；没有订单提交、撤单或交易入口。
- 只有 HTTP 200 且返回预期 JSON 结构的请求计入成功耗时。401、403、429 或 HTTP 200 错误页不计入成功样本；遇到 401/429 停止当前测试。
- 直连与代理使用独立的 Node.js HTTPS 连接池；直连忽略环境代理，代理使用显式 HTTP CONNECT。两者都验证 Schwab 的 TLS 证书，不自动跟随重定向。透明 VPN/TUN 或上游网络路由仍由操作系统与网络决定。授权交换及令牌刷新使用直连，不计入测速样本。
- 页面和 API 限制 Host、Origin、CSRF，禁止跨站嵌入；此原型不适合暴露到公网。
- 自动刷新只在当前运行进程、已有刷新令牌且需要请求时发生。需要重新授权时由用户在 Schwab 官方页面登录。

```powershell
node --test .\tools\schwab-connect\test\*.test.mjs
```

测试使用虚构密钥和模拟券商响应，不调用真实账户。覆盖 OAuth 回调注入/过期/重复、密钥与金融数据输出隔离、令牌刷新、业务成功样本判定、接口白名单、本机来源校验、对比顺序、预热排除及代理失败隔离。

已完成 Windows 本机真实 Schwab 授权及账户、行情直连和代理对比，结果位于项目 `reports/`。2026-09-05 23:06 的对比完成 60 次成功正式请求及 4 次预热，其中代理账户预热连接失败，该组后续请求被跳过；见 `reports/authenticated-proxy-comparison-20260905-230612.md`。尚未测量 iPhone 网络，也未完成 iOS 编译签名。后续 iOS 版本可使用 Keychain 保管个人凭据和令牌；自动 HTTPS 回调需要额外的关联域名配置，当前手动流程不依赖它。
