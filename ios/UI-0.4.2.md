# 0.4.2 个人版首次连接

当前为待原生编译验证的 0.4.2 / build 6 源码，包含 0.4.1 的 K 线手势。现有已验证的安装包和本地原生截图预览仍为 0.4.0，没有用旧二进制冒充新版。

## 首次使用和再次打开

个人版从安装包读取应用配置，成功保存到设备钥匙串后，直接打开“连接”页显示 Schwab 登录按钮。本人仍需在券商页面完成账户登录及授权，再主动粘贴最终回调链接。应用配置不会代替账户授权。

已保存的设备配置优先于安装包；再次打开、重新授权、普通断开连接以及覆盖安装不会主动覆盖旧配置或要求重新填写。更换签名团队可能改变钥匙串访问权限，届时能否沿用原会话仍需真机验证。用户明确删除本机凭据时，只保存禁止自动导入的标记，避免下一次启动又自动恢复。删除后可手动配置。

首次读取或写入钥匙串失败不会被当作加载成功，返回 App 或点击重试可以重新读取。手动保存失败时保留输入，成功后清空界面中的文字。

## 配置进入安装包的方式

SwiftUI 代码新增 `PersonalSchwabConfiguration`，读取约定的 `SchwabPersonalConfiguration.plist`，校验格式后复用现有会话和钥匙串存储。没有新增 App 依赖，也没有另建凭据数据库。`Info.plist` 仅增加格式版本标记。

云端只编译不含个人配置的通用 App。`tools/ios/personalize-ipa.py` 在本机读取 `.env` 中两项应用凭据，向通过原生验证的未签名 IPA 追加配置文件；输入包保持不变。个人 IPA 包含可提取的应用凭据，只供自己的设备签名安装。注入工具不导入账户号码、OAuth token 或密码，也不向任何服务上传内容。

没有配置的通用包继续提供手动输入。旧 0.4.0 二进制没有配置加载功能，本地工具会拒绝把它包装成免填写个人版。

## 检查与剩余验证

- Python 工具使用合成 ZIP、Mach-O 命令表和虚构配置，验证拒绝旧包、签名材料、异常路径、覆盖输出以及错误脱敏；这些检查不代表 iOS 程序已编译运行。
- 原生测试覆盖首次导入、已保存会话优先、删除后的禁止导入、存储失败重试及格式验证。新增界面测试只用虚构配置，检查首次启动出现登录入口且没有 Client ID / Secret 输入框。
- Release 包校验拒绝 UI 测试开关，并区分通用包与本机追加配置后的个人包。
- 完整 XCTest、原生截图核对和 Release 归档仍待 EAS 的 Mac 构建机运行；本机 Windows 无 Xcode。没有进行真实账户请求或订单操作。

EAS 配置和免费构建步骤见 [EAS-BUILD.md](EAS-BUILD.md)，本地追加配置方式见 [个人 IPA 工具说明](../tools/ios/README-personal-ipa.md)。在新版通过检查前保留旧交付。
