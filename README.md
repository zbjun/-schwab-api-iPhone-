# THS · 个人 iPhone 交易客户端

基于 **Expo / React Native** 的个人 Schwab 股票／ETF 客户端，包含行情图表、账户持仓、买卖撤单和双设备共享授权。支持跟随系统明暗主题，提供浏览器演示、Expo Go 调试及独立 iPhone IPA。

行情优先使用推送，界面按 250ms 合并更新；当前周期蜡烛随收到的成交价变化，推送不可用时回退轮询。图上支持 **B/S 成交标记和平均成本虚线**。行情页或订单页在前台时，有未完成订单约每 2 秒同步订单，空闲时约每 5 秒同步；收到成交明细后自动更新 B/S 点，不重载整张图。以上轮询间隔不包含网络耗时，失败会退避。

最新源码的服务器共享模式增加账户事件通知：收到成交／撤单等通知即合并刷新资金、持仓、订单和 B/S 点，保留低频核对与断线轮询。极速下单在一次服务器请求中完成一轮最新数据校验和提交；普通确认模式保持双阶段核对。真实提速幅度与券商延迟仍需部署后测量，参见[服务器配置与边界](server/README.md)。

### 本地市价单：价格优先模式

这是 App 在前台管理的限价执行策略：买入默认从买一向卖一靠近 **25% 价差**，卖出反向计算；首次等待后最多让到中间价。价格变化达到设定的间隔和最小价位数才撤改，先确认原单撤销及已成交数量，再提交剩余股数。

起挂比例、固定价格边界、执行时长、改单间隔、最小改价、价格突变和最大价差阈值都在设置中调整。越界、超时或触发异常报价条件后停止并撤销剩余委托，不自动重启。**价格优先可能无法成交；参数未经回测证明最优，也不是券商原生市价单。** 详见 [参数与执行规则](mobile/README.md#本地市价单参数)。

### 延长时段与夜盘

图表按美东时间标记夜盘、盘前、盘中和盘后，显示收到的有效行情，并保留符合条件的已读取分钟历史。点击时段说明可以查看已加载日期与覆盖范围；没有返回的数据不会被伪造补齐。

历史只读验证记录包含 QQQ、SNDK 的部分夜盘分钟线，**不代表每只股票、每晚都能取得完整夜盘数据**。`24` 是有来源日期和有效期的参考标记，不等于实时交易权限。现有盘前／盘后及连续延长时段下单使用限价；连续延长时段不包含夜盘，客户端尚未提供夜盘下单时段。

## 快速开始

在仓库根目录执行：

```powershell
cd mobile
npm ci
npm run web
```

按终端地址打开浏览器，默认 `http://localhost:8081`。**网页仅用于演示，不进行真实交易。** 开发预览支持 `?appearance=dark` 或 `?appearance=light`。

iPhone 调试：安装支持项目 SDK 的 Expo Go，手机与电脑连接同一局域网；从仓库根目录运行：

```powershell
./tools/Start-ExpoGo.ps1
```

扫描终端二维码，保持电脑和 Metro 服务运行。日常源码热更新无需触发 EAS 云端构建。独立 IPA 的构建和本地个性化步骤见 [mobile/README.md](mobile/README.md#独立-ipa)。

## 授权和交易边界

- **服务器共享模式**：服务器统一维护 Schwab OAuth 令牌；每台设备保存独立访问密钥。服务器已授权时，两台设备共享授权状态，无需分别登录券商。Schwab 要求重新授权时，仍须本人在官方页面完成一次授权。
- **直连模式**：设备保存自己的配置和会话，沿用手动粘贴 OAuth 回调。账号密码只在 Schwab 官方登录页面填写。不要让旧直连客户端和共享服务器同时刷新同一应用会话。
- **快速模式**：本人点击买入、卖出或单笔撤单后直接核对并提交，省去二次确认；仍保留账户、数量、冻结订单快照和未知结果保护。
- 提交、修改、撤单回执不代表成交。结果不明的写请求不会自动重试；共享服务器的未知结果锁影响所有设备，需核对券商记录后恢复。
- 订单读取窗口为近 30 天、最多 200 笔。可买可卖是估算，不证明更早的 GTC 委托不存在；达到查询上限时拒绝准备新交易。期权、卖空、碎股和复杂组合单不由简单股票编辑器处理。
- 真实凭据、设备密钥、令牌、个人 IPA 和诊断原始数据不随源码公开。通用包不含个人连接；自用配置仅在本机追加。仓库里的演示数据不用于补充真实账户数据。
