# 0.3.0 行情与交易界面

用户已确认开始实施此前收集的三项 UI 需求。以已验证的 0.2.0 为基线，保留授权、不可变订单核对及防重复提交逻辑，无新增第三方依赖。

## 实施顺序

1. 扩展五种历史区间、OHLC 与均线计算，核实统计字段，使用纯模型测试验证计算与缺失值。
2. 自选改为紧凑深色表格，左滑切换同列分时图；删除自选使用明确编辑入口。
3. 详情改为紧凑行情摘要、五种图表及成交量；图下买卖区单独占用布局空间，键盘出现仍保持图表可见。
4. 共用整股/金额换算与账户数量估算逻辑；按金额买入换算为限价整股订单，避免把预算当作可保证的市价成交金额。
5. 原生界面测试覆盖模式切换、K 线/均线、买卖区不遮挡、金额买入及既有撤改流程；导出截图按用户参考进行视觉检查，再打包新版本。

## 保留与简化

既有 63 项单元测试和 5 项界面测试锁定账户、授权与订单行为。订单写请求服务不改变；共享数量/金额校验避免两个买卖入口采用不同换算方式。完整订单表单继续支持四种订单，图下表单复用同一提交核对状态机。

## 数据与验收约定

- 黄色线为分钟 OHLCV 估算的加权均价，按纽约交易日期重置；不冒充逐笔成交均价。缺失成交量时不生成假均线。
- 日、周、月 K 的 MA5/10/20/30 按当前蜡烛周期计算，足够样本之前不填充均线。
- 统计和最大可买/卖数量必须有数据依据；账户证券权限、未完成委托和行情变化使数量只能作为估算，最终核对仍由券商决定。
- 按金额输入使用美元预算，向下换算整股，金额和限价变化均使旧核对失效；不新增碎股或自动下单。
- 不遮挡验收：图表底边不超过买卖区顶边；键盘出现后图表仍有可见高度，表单在自己的区域滚动。
- 参考中的品牌、广告、付费指标、A 股特有功能不纳入本轮。

本轮实际测试、截图和打包证据在完成后更新。
