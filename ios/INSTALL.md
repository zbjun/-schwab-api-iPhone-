# THS 安装与后续真机调试

本轮为 **0.4.0 系统配色、分钟 K 线与图下撤单更新**。云端 117 项原生测试、iPhone Release 归档和本地安装包校验均已通过，可使用对应归档进行签名安装调试。旧版安装包仍保留，后续使用 0.4.0。

## 本地交付文件

本轮交付文件已保存在项目的 `artifacts` 目录：

- `THS-0.4.0-unsigned.ipa`：供本人安排签名的 iPhone 安装包。
- `THS-0.4.0-signing-kit.zip`：安装包、本说明、SHA-256 及包验证记录。
- `THS-0.4.0-verification.json`：版本、设备平台、架构及未签名状态的检查结果。
- `preview-0.4.0/index.html`：可直接打开的原生界面截图浏览页，图片均为演示数据。

具体构建编号和已完成的测试见 [实现与验收](IMPLEMENTATION.md)。签名包附带本说明的当前副本；仓库中的说明为后续更新来源。

## 功能完成后安装

1. 从通过验证的最新云端构建下载 THS-unsigned-iPhone 附件，或使用本地已下载的对应版本 IPA。
2. 把未签名 IPA 交给自己安排的签名服务。Bundle ID 默认为 `app.personal.ths`，签名方不需要 Schwab Client Secret、账户密码或授权回调链接。
3. 按签名方要求登记设备并签名，然后安装到 iPhone。未签名 IPA 不能直接安装；签名会改变文件校验值。
4. 先开启“连接 → 演示模式”，在自己的手机上走查查价、图表、下单核对及模拟撤改。
5. 演示通过后，关闭演示，在手机上输入 Schwab 应用凭据并完成授权。

[自己的私有仓库](https://github.com/zbjun/ths-ios-personal) · [构建与附件](https://github.com/zbjun/ths-ios-personal/actions/workflows/ios.yml)

云端 IPA 附件保留 14 天，测试结果保留 7 天。已下载的本地副本不受云端附件期限影响。签名服务若要求其他 Bundle ID，工作流提供对应输入；默认不上传 App Store。

## 手机上的首次授权

Callback URL 应为 `https://127.0.0.1`。在 App 的“连接”页保存 Client ID / Client Secret，点击“打开 Schwab 登录”，在券商页面填写券商密码并确认授权。浏览器转到本机地址显示无法连接后，复制地址栏完整链接，回到 App 主动粘贴并完成连接。

电脑之前的授权不会自动迁移到手机。凭据和令牌仅存在手机钥匙串，回调链接也不要发给签名服务。

## 真机调试顺序

- 切换 iPhone 16 Pro 的系统明暗模式，核对自选与详情同步变化、左滑多股走势和返回导航。
- 检查五个主图选项，以及“更多”中的六种分钟蜡烛和 MA5/10/20/30。
- 展开图下买卖区，确认键盘出现后仍能看清主图；检查大字体、按金额换算和买卖预估数量。
- 检查“买 / 卖 / 撤”切换，先用演示委托走通选单、保留订单返回和确认撤销，核对区不能遮挡主图。
- 使用真实授权只读核对账户尾号、持仓、报价时间、订单状态和图表。
- 分别测试 Wi-Fi 与蜂窝网络的直连及失败恢复，再验证关闭重开 App 和令牌刷新。
- 最后才由本人填写并确认真实订单，检查券商回执和实际订单状态；开发测试没有替你发送真实订单。

如果提交或撤改结果不确定，先查看券商订单。App 不会自动重新发送。只有本人核实上次结果后，才通过“我已核对”解除本机提示。

有 Mac 时可打开 `ios/THS.xcodeproj`，选择 THS Scheme、自己的开发团队和设备，先 Test 再 Run。本机 Windows 负责源码与工程检查，原生编译和模拟器验证使用云端 Xcode。
