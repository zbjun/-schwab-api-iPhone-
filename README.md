# THS · 基于schwab api的个人 iPhone 交易客户端

基于 **Expo / React Native** 的个人交易客户端，连接 **Schwab 股票／ETF** 和 **MEXC USDT 永续合约**，两边在同一套页面里：一个自选列表、一个账户页、一个订单列表，不用切换。包含行情图表、账户持仓、买卖撤单和双设备共享授权。支持跟随系统明暗主题，提供浏览器演示和独立 iPhone IPA。

## 当前功能

股票和合约共用账户、自选、交易、订单、设置五个页面。合并的只是显示：两边各有自己的连接、核对和交易锁，一边结果未知时只锁那一边。没有连 MEXC 的手机只显示股票内容。

### Schwab 股票／ETF

| 页面 | 功能 |
| --- | --- |
| 账户 | 净值、现金、购买力、持仓和平均成本；前台账户页约每 5 秒自动刷新，支持下拉刷新 |
| 自选 | 最多 50 个代码、列表／多股同列；持仓代码和名称用主题强调色，`24` 标记隔夜资格参考名单 |
| 行情 | 分时、五日、日／周／月 K，以及 1／5／15／30／60／120 分钟 K；均价估算和 MA5/10/20/30 |
| 图表交互 | 单指拖动、双指缩放、长按十字线、轻点退出、返回最新；选中蜡烛联动价格及高低开、成交量等数据 |
| 交易 | 紧凑下单面板：买一／卖一／最新点选填价、价格和数量步进、拖动仓位条选数量、底部悬浮提交；整股数量和金额换算、可买可卖估算、时段选择 |
| 止盈止损 | 嘉信托管：买入时附带（成交后自动挂出）、给已有持仓设置（OCO，一个成交另一个自动撤销）、固定止损价或移动止损（价差／百分比）；同一组止盈止损只占用一次可卖股数 |
| 定时单 | 服务器到点提交：按美东时间设置，到点重新核对资金、持仓和报价后只发送一次；错过或核对不通过即放弃，不补发；订单页可查看和撤销 |
| 订单 | 状态筛选、自动更新；点订单进入股票行情，详情在该行下方展开，支持核对、撤单及简单订单修改；联动委托可整组或单腿撤销；成交记录可导出 CSV（逐笔，精确到秒，最多 60 天） |
| 设置 | Schwab 连接、快速模式、本地市价执行参数；iOS 26 原生 Liquid Glass 悬浮页签栏和按钮，明暗主题自动切换 |

行情优先使用推送，界面按 250ms 合并更新；当前周期蜡烛随收到的成交价变化，推送不可用时回退轮询。图上支持 **B/S 成交标记和平均成本虚线**。行情页或订单页在前台时，有未完成订单约每 2 秒同步订单，空闲时约每 5 秒同步；收到成交明细后自动更新 B/S 点，不重载整张图。以上轮询间隔不包含网络耗时，失败会退避。

最新源码的服务器共享模式增加账户事件通知：收到成交／撤单等通知即合并刷新资金、持仓、订单和 B/S 点，保留低频核对与断线轮询。极速下单在一次服务器请求中完成一轮最新数据校验和提交；普通确认模式保持双阶段核对。真实提速幅度与券商延迟仍需部署后测量，参见[服务器配置与边界](server/README.md)。

### 本地市价单：价格优先模式

这是 App 在前台管理的限价执行策略：买入默认从买一向卖一靠近 **25% 价差**，卖出反向计算；首次等待后最多让到中间价。价格变化达到设定的间隔和最小价位数才撤改，先确认原单撤销及已成交数量，再提交剩余股数。

起挂比例、固定价格边界、执行时长、改单间隔、最小改价、价格突变和最大价差阈值都在设置中调整。越界、超时或触发异常报价条件后停止并撤销剩余委托，不自动重启。**价格优先可能无法成交；参数未经回测证明最优，也不是券商原生市价单。** 详见 [参数与执行规则](mobile/README.md#本地市价单参数)。

### 延长时段与夜盘

图表按美东时间标记夜盘、盘前、盘中和盘后，显示收到的有效行情，并保留符合条件的已读取分钟历史。点击时段说明可以查看已加载日期与覆盖范围；没有返回的数据不会被伪造补齐。

历史只读验证记录包含 QQQ、SNDK 的部分夜盘分钟线，**不代表每只股票、每晚都能取得完整夜盘数据**。`24` 是有来源日期和有效期的参考标记，不等于实时交易权限。现有盘前／盘后及连续延长时段下单使用限价；连续延长时段不包含夜盘，客户端尚未提供夜盘下单时段。

### MEXC USDT 永续合约

只做永续合约，不接现货账户。所有请求经独立的 MEXC 网关发出，手机上不保存交易所 key。

| 页面 | 功能 |
| --- | --- |
| 自选 | 收藏的合约和股票在同一个列表，可按全部、股票、合约筛选；搜索或“所有合约”里点星标添加 |
| 合约图 | 分时、1 时、日及更多周期；每秒刷新，当前 K 线随行情变化，显示收线倒计时；图上有 B/S 成交点、成本线和止盈止损线；长按时头部显示所选 K 线的价格、开高低、量和时间 |
| 开仓和平仓 | 在合约页内直接下单，不跳转；限价或市价；拖动仓位条选择数量并带振动反馈；平仓时显示预计盈亏 |
| 杠杆 | 下单时设置，已有持仓也可以修改 |
| 止盈止损 | 开仓时附带，也可以给已有持仓设置、修改或撤销；按标记价触发，以市价退出；设置、核对、持仓页和图上的线都显示预计盈亏 |
| 账户和订单 | 账户页显示余额和持仓，点持仓进合约页；订单和 Schwab 排在同一个列表，可按交易场所和状态筛选，可导出 CSV |

网关只能按合约查已结束的委托，所以列表和导出只包含持仓、挂单、近期交易过和收藏的合约，最多 20 个；导出按委托汇总，不是逐笔成交。

B/S 点只画在已加载的 K 线范围内，所以周期越短，能看到的成交点越少。预计盈亏是估算，没扣手续费和资金费；止损以市价平仓，行情剧烈时实际亏损可能更大。

### 后台小窗（iOS）

开着合约页回到桌面时，K 线会以画中画形式继续浮在屏幕上，显示最新价、倒计时、行情时间、成本线和止盈止损线；点合约页的"小窗"按钮可以手动打开或关闭。

- **只读**：小窗只请求网关的 `live` 行情接口，不能下单、改单或撤单。
- **过时提示**：5 秒没收到有效回复，或行情 30 秒没有变化，价格变灰并提示"连接中断，价格不是最新"；止盈止损线超过 60 秒没有更新时变灰并标出时间。
- **已知缺口**：如果系统把 App 挂起，画面会直接停住，也无法显示警告，只能从行情时间和停走的倒计时看出来。**据此下单前请先回到 App 确认价格。**
- **系统要求**：它使用音频后台模式保持运行，但不播放声音；Expo Go 和网页里没有这个功能，只能在独立 IPA 里使用。

## 快速开始

在仓库根目录执行：

```powershell
cd mobile
npm ci
npm run web
```

按终端地址打开浏览器，默认 `http://localhost:8081`。**网页仅用于演示，不进行真实交易。** 开发预览同时显示两边的演示账户，支持 `?appearance=dark` 或 `?appearance=light`；`?preview=no-mexc` 模拟没有连 MEXC 的手机。

iPhone 调试：安装支持项目 SDK 的 Expo Go，手机与电脑连接同一局域网；从仓库根目录运行：

```powershell
./tools/Start-ExpoGo.ps1
```

扫描终端二维码，保持电脑和 Metro 服务运行。App Store 的 Expo Go 只支持最新 SDK，如果和项目的 SDK 57 不一致，可以用手机 Safari 打开同一个 Metro 地址预览界面。日常源码热更新无需触发 EAS 云端构建。独立 IPA 的构建和本地个性化步骤见 [mobile/README.md](mobile/README.md#独立-ipa)。

## 授权和交易边界

- **服务器共享模式**：服务器统一维护 Schwab OAuth 令牌；每台设备保存独立访问密钥。服务器已授权时，两台设备共享授权状态，无需分别登录券商。Schwab 要求重新授权时，仍须本人在官方页面完成一次授权。
- **直连模式**：设备保存自己的配置和会话，沿用手动粘贴 OAuth 回调。账号密码只在 Schwab 官方登录页面填写。不要让旧直连客户端和共享服务器同时刷新同一应用会话。
- **快速模式**：本人点击买入、卖出或单笔撤单后直接核对并提交，省去二次确认；仍保留账户、数量、冻结订单快照和未知结果保护。
- 提交、修改、撤单回执不代表成交。结果不明的写请求不会自动重试；共享服务器的未知结果锁影响所有设备，需核对券商记录后恢复。
- 订单读取窗口为近 30 天、最多 200 笔。可买可卖是估算，不证明更早的 GTC 委托不存在；达到查询上限时拒绝准备新交易。期权、卖空、碎股和复杂组合单不由简单股票编辑器处理。
- **MEXC**：API key 只保存在 MEXC 网关的服务器配置里，不进手机、不进仓库；key 的 IP 绑定和权限由本人在 MEXC 页面确认。下单、改杠杆和止盈止损都要先核对，核对 60 秒内有效且只能用一次；写请求不自动重试。设置里的 MEXC 快速模式默认关闭，开启后点开多、开空、平仓或撤单即提交，只省掉看核对页这一步，服务器仍做同样的核对；带止盈止损的开仓、限价离最新价超过 5% 的委托、改杠杆和止盈止损仍要确认。结果未知时锁住所有写操作，到交易所核对后才能在服务器上解锁，只有文档明确的拒绝码才会直接解锁。杠杆和单笔金额上限由服务器校验，市价单以带保护价的 IOC 发出。
- 真实凭据、设备密钥、令牌、个人 IPA 和诊断原始数据不随源码公开。通用包不含个人连接；自用配置仅在本机追加。仓库里的演示数据不用于补充真实账户数据。
