# THS Expo / React Native

当前开发客户端使用 **Expo SDK 57 / React Native 0.86 / React 19.2**，应用配置为 **0.6.2（iOS build 9）**。项目入口、功能概览见[仓库首页](../README.md)，详细证据见[验证记录](VERIFICATION.md)。

截至 2026-09-11，最近交付的 0.6.2（9）IPA 来自 `050067f`。此后的价格优先本地市价、统一页面布局、自动同步 B/S 点和订单导航等修改已进入源码，**尚未重新打包**。版本配置相同不代表安装包已包含最新提交。

## 本地预览与 Expo Go

在 `mobile/` 目录安装依赖并启动：

```powershell
npm ci
npm run web
```

按终端地址打开网页，默认 `http://localhost:8081`；开发模式可加 `?appearance=dark` 或 `?appearance=light`。网页仅允许演示账户，演示订单不会发送到 Schwab。

在 iPhone 调试：

1. 安装支持 Expo SDK 57 的 Expo Go。
2. 手机与电脑连接同一局域网，从仓库根目录运行 `./tools/Start-ExpoGo.ps1`；也可在本目录运行 `npm start`。
3. 扫描终端二维码，允许本地网络访问，并保持电脑和 Metro 运行。连接地址以当次终端输出为准，不使用旧截图中的地址。

JavaScript、TypeScript 和界面修改通过 Fast Refresh 更新，不触发 EAS 构建；原生配置或模块变化不等同于普通热更新。独立 IPA 与 Expo Go 不共享设备存储或连接配置。

## 连接 Schwab

连接入口位于 **设置 → Schwab 连接**。账号密码始终在 Schwab 官方页面输入，不由 App 收集。

### 两台设备共享服务器授权

服务器集中保存 Client ID、Client Secret 和 OAuth 令牌，两台设备各自保存 HTTPS 服务器地址及不同的设备密钥。已有 HTTPS 部署和双设备配置只读验证记录，见[服务器部署记录](../server/DEPLOYMENT.md)与[客户端验证记录](VERIFICATION.md)。记录中的授权状态只代表验证当时，当前状态以 App 为准。

1. 在每台设备选择“服务器共享”，填写同一服务器地址及各自密钥，或导入本机生成的设备配置。
2. 服务器尚未授权时，从 App 打开 Schwab 官方授权页面。开发者门户须登记与服务器配置完全一致的 `https://你的域名/oauth/callback`。
3. 授权回调由服务器接收，完成后返回 App 并刷新连接。服务器授权有效时，另一台设备直接共享结果，无需再次登录 Schwab。

两台手机使用同一套业务代码；不同自用 IPA 只是分别预置设备密钥。手机断开只移除本机配置，服务器可单独撤销设备密钥。迁移后停止旧直连客户端刷新同一应用会话。服务器无法免除 Schwab 后续要求的重新授权。

部署、单进程运行和结果不明恢复步骤见 [server/README.md](../server/README.md)，设计约束见[多设备连接](MULTI-DEVICE.md)。手机不接收服务器里的 Schwab 令牌或 Client Secret。

### Schwab 直连

直连模式可从 iPhone“文件”导入个人应用配置，例如本机私有的 `artifacts/THS-Expo-personal-config.json`，或填写应用配置。导入后保存到 SecureStore，重启可恢复。

使用开发者门户已登记、且与配置完全一致的回调地址。旧直连配置使用 `https://127.0.0.1`：官方授权后 Safari 可能显示无法访问，复制地址栏完整回调网址，回 App 粘贴并完成授权。Expo Go 不提供此项目独立的原生回调入口，直连仍使用手动回填。

个人配置、设备密钥和回调中的授权码均不应提交 Git、公开分享或放入云端构建上传目录。

## 页面与图表

- 五个主页面为账户、自选、交易、订单、设置，统一左侧标题、分组卡片和系统明暗色。账户、自选、交易、订单使用下拉刷新；账户页在前台约每 5 秒自动读取资金与持仓。
- 分时／五日显示折线与黄色均价估算；日／周／月和 1／5／15／30／60／120 分钟 K 显示蜡烛及 MA5/10/20/30。统计中的换手、均价或成交额估算有相应标识。
- 横向拖动、双指缩放、返回最新；长按约 0.45 秒开启十字线，移动选中蜡烛，轻点退出。选中价格、高低开、成交量等随选点变化；历史成交额及换手仅在可计算时显示估算。
- B/S 标记来自券商成交明细，成本虚线来自当前持仓。行情页／订单页在前台自动读取订单：有未完成订单时读取完成后等待 2 秒，否则等待 5 秒。收到延迟或部分成交后自动更新标记，不重载历史或重置图表位置；失败退避，离页或后台停止。
- 行情优先采用推送，每 250ms 合并界面更新；当前蜡烛随收到的成交价形成，成交量可能待后续校准。推送不可用时回退轮询。五档界面已移除，保留买一／卖一报价。
- 点订单行或箭头进入股票行情；“订单详情”在当前行下面展开，可核对、撤单或修改简单订单。图下“撤”页仍用于查看和管理当前证券委托。

### 夜盘数据与 `24` 标记

图表保留收到的有效夜盘、盘前和盘后数据，并以时段底色区分。点击时段说明可查看覆盖日期并定位已加载区间；部分历史刷新缺漏时，会在既定范围内保留此前读取的有效分钟线。

验证记录已确认 QQQ、SNDK 在特定日期有夜盘分钟线，但 SNDU 和部分日期仍存在未返回的区间。客户端不会凭空补数据；这些记录不能证明当前所有股票、所有夜盘都完整可用。具体历史样本见[夜盘诊断](OVERNIGHT-DIAGNOSTIC.md)，后续检查见 [VERIFICATION.md](VERIFICATION.md)。

自选中主题强调色的名称／代码表示当前账户有持仓。金色 `24` 是带来源日期的隔夜资格参考名单，超过 30 天暂停显示；不是实时权限查询，未标记也不代表不支持。名单位于 `src/overnightReference.ts`，不启用夜盘交易。

## 交易与快速模式

支持整股股票／ETF。常规时段可选市价、限价、止损市价、止损限价；盘前、盘后及连续延长时段使用限价。盘前／盘后仅 DAY，常规限价和连续延长时段可选 DAY/GTC。连续延长时段不包含夜盘，当前没有夜盘下单时段。

图下买／卖／撤面板保留图表空间，展示买一卖一，点击报价可填入限价。按金额买入向下换算整股，金额不含费用。可买可卖数量按资金、持仓和已读订单估算；订单窗口为最近 30 天、最多 200 笔，达到上限时拒绝准备新交易，不能据此证明更早 GTC 委托不存在。

**快速模式默认关闭，开关在设置中。** 开启后本人点击买入／卖出或单笔撤单会直接核对并提交，省去二次确认；修改订单仍需核对。普通模式保留确认页。两种模式共用冻结快照、账户数量校验和未知结果锁定。点击普通订单行是导航，不执行撤单。

### 本地市价单参数

本地市价单现采用**价格优先**策略，实际发送限价委托。设价差为 `卖一 − 买一`：

- 买入起挂价：`买一 + 价差 × 起挂比例`。
- 卖出起挂价：`卖一 − 价差 × 起挂比例`。
- 首笔挂单等待达到改单间隔后，最多让到中间价。买价向下、卖价向上按合法价位取整。
- 新目标与当前挂价相差达到最小价位数，且当前委托已等待足够时间，才撤改。向更优价格和向中间价让价均遵守此规则。
- 原委托确认撤销并核对部分成交后，才发送剩余股数；不因撤单回执而假定撤单完成。

所有参数均位于 **设置 → 本地市价单**，交易面板只显示摘要：

| 参数 | 新增参数初始值／规则 |
| --- | --- |
| 起挂位置 | 买卖价差的 25%，可设 0–50% |
| 价格边界 | 保留已有设置；首次使用需填写。相对启动中间价固定，不随改单放宽 |
| 最长执行 | 保留已有设置；首次使用需填写，1–3600 秒 |
| 最短改单间隔 | 5 秒，可设 2–60 秒 |
| 最小改价 | 2 个最小价位，可设 1–100 |
| 3 秒突变阈值 | 观察到的中间价变化超过 0.5% 时停止，可调整 |
| 最大价差 | 买卖价差／中间价超过 1% 时停止，可调整 |

旧版按股价计算的“滑点”不会被当成新版价差比例，旧价格边界和执行时长保留。超时、超界、报价缺失／过期、突变或价差超限会停止并尝试确认撤销剩余委托，不自动重启。读报价有采样与网络延迟，不能保证捕捉所有瞬时变化。

这是可调整的工程起点，未经回测证明最优，**不保证成交或最低买价／最高卖价**。策略在 App 前台执行，不是服务器后台托管；退出、杀进程或断网后不能保证自动撤单，须核对券商委托状态。本地策略不扩展券商支持的交易时段。

## 独立 IPA

在 `mobile/` 内使用 `eas.json` 的 `unsigned` 配置构建。云端 macOS/Xcode 生成 Release 真机包并嵌入 Hermes bundle，当前脚本输出 `THS-0.6.2-unsigned.ipa`。需用自己的证书签名安装，之后不依赖 Metro、Expo Go 或电脑。推送源码不会触发 IPA 构建。

明确需要新 IPA 并核对 EAS 账户额度后，在本目录执行：

```powershell
$env:EAS_NO_VCS='1'
$env:EAS_PROJECT_ROOT=(Get-Location).Path
$env:EXPO_NO_DOTENV='1'
npx eas-cli@23.2.0 build --platform ios --profile unsigned --non-interactive
```

**不要从仓库根目录运行该构建命令**，根目录配置仍对应旧 SwiftUI 项目。`.easignore` 限定上传范围，个人配置不进入通用云端构建。已有 macOS/Xcode 环境也可在本目录运行 `bash scripts/build-unsigned-ios.sh`。

服务器共享自用包在本机追加设备配置，例如在 `mobile/` 执行：

```powershell
python scripts/personalize-ipa.py INPUT.ipa OUTPUT.ipa --server-device ../artifacts/server-device-configs/device-1.json
```

另一设备使用自己的配置文件。上述 `artifacts/` 文件由使用者私下生成，不在仓库中。自用包首次启动导入该设备连接；已有配置优先，显式断开后不会重复自动导入。服务器授权有效时无需再登录 Schwab；没有预置配置的通用包需要自行连接。直连自用配置的参数见 `python scripts/personalize-ipa.py --help`。

更新版本时需同步应用配置、构建脚本和构建产物路径，并重新验证。仅修改 README 或提交源码不会改变已交付 IPA。

## 验证与开发

在 `mobile/` 执行：

```powershell
npm run typecheck
npm test
npm run export:web
npm run export:ios
```

`export:ios` 只验证 JavaScript／Hermes 导出，不构建或签名 IPA，也不验证真机手势、网络或实盘成交。当前客户端最近验证为 **252 项测试通过**；演示浏览器另验证普通／快速模式、延迟 B/S 标记同步、订单导航和明暗布局。完整范围与日期见 [VERIFICATION.md](VERIFICATION.md)。

延迟成交标记的网页回归脚本位于 `../tools/verify-order-marker-sync.cjs`，需要外部已安装的 Playwright，可通过 `PLAYWRIGHT_MODULE` 指向其模块、`BROWSER_EXECUTABLE` 指定浏览器。脚本使用隔离的演示账户，不提交真实订单。

所有写请求均不自动重试；结果不明时保留交易锁，服务器共享模式会影响两台设备。核对券商记录后按[服务器恢复流程](../server/README.md#orders-and-recovery)处理，不删除令牌库绕过未知结果。演示数据不会填入真实账户缺失的数据。
